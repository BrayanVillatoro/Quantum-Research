# Timeline

| Year | Milestone |
|---|---|
| 1982 | Richard Feynman argues that simulating physics needs quantum computers |
| 1985 | David Deutsch describes a universal quantum computer |
| 1994 | Peter Shor finds a quantum algorithm that factors large numbers fast, which threatens today's encryption |
| 1995 | Shor publishes the first quantum error-correcting code |
| 1996 | Lov Grover finds a quantum algorithm for searching unsorted data |
| 1998 | First small quantum algorithms run on real hardware (NMR) |
| 1999 | First superconducting qubit demonstrated (Nakamura, Pashkin, Tsai) |
| 2001 | IBM and Stanford use Shor's algorithm to factor 15 |
| 2011 | D-Wave sells the first commercial quantum annealer |
| 2016 | IBM puts a quantum computer on the cloud for anyone to use |
| 2017 | IBM releases Qiskit |
| 2019 | Google claims quantum supremacy with its 53-qubit Sycamore chip |
| 2020 | USTC in China claims quantum advantage with the photonic Jiuzhang machine |
| 2023 | Harvard and QuEra run algorithms on 48 logical qubits |
| 2024 | Google's Willow chip shows errors falling as the error-correcting code grows |
| 2025 | Microsoft announces Majorana 1 (topological); AWS announces Ocelot (cat qubits) |
