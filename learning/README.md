# Learning path

Work through these in order. For each topic, write a short note in this folder
in your own words (for example `01-linear-algebra.md`) and tick it off.

- [ ] **1. Linear algebra**: complex numbers, vectors, matrices, inner products, eigenvalues, tensor products
- [ ] **2. Qubits**: superposition, the Bloch sphere, measurement
- [ ] **3. Gates and circuits**: X, Y, Z, H, S, T, CNOT; reading and drawing circuits
- [ ] **4. Entanglement**: Bell states, why entangled qubits can't be described separately
- [ ] **5. Protocols**: teleportation, superdense coding
- [ ] **6. First algorithms**: Deutsch–Jozsa, Bernstein–Vazirani
- [ ] **7. Grover's search**: amplitude amplification
- [ ] **8. Quantum Fourier transform and Shor's algorithm**: phase estimation, factoring
- [ ] **9. Noise**: decoherence, gate errors, density matrices
- [ ] **10. Error correction**: bit-flip and phase-flip codes, the surface code, logical qubits
- [ ] **11. Near-term algorithms**: VQE, QAOA
- [ ] **12. Hardware**: how the qubit types in [../industry/qubit-types.md](../industry/qubit-types.md) actually work
